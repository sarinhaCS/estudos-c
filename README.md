# C Estudos

Repositório com exercícios em C, organizados por tema.

## Conteúdo
- Fundamentos
- Condicionais
- Laços de repetição
- Strings
- Funções
- Vetores e matrizes
- Arquivos
- Ponteiros
- Desafios

## Como compilar
Exemplo com GCC
-> gcc 01-fundamentos/entrada-saida.c -o saida.exe

## Como executar
-> ./saida

## Objetivo
Praticar lógica, sintaxe da linguagem C e organização de código.
