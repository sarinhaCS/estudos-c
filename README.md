# Estudos em C
Repositório mostra minha evolução na linguagem C, com tópicos organizados por tema.

## Conteúdo
- Fundamentos
- Condicionais
- Laços de repetição
- Strings
- Funções
- Vetores e matrizes
- Arquivos
- Ponteiros
- Desafios

## Como compilar no terminal
Exemplo com GCC
-> gcc 01-fundamentos/entrada-saida.c -o saida.exe

## Como executar no terminal
-> ./saida

## Objetivo
Praticar lógica, sintaxe da linguagem C e organização de código.
